# counttoken

Count timestamps and token durations for scripts and CI receipts.

**Site:** https://theworker02.github.io/counttoken/

## Install / run

```bash
git clone https://github.com/theworker02/counttoken.git
cd counttoken
node src/cli.js
node --test
```
